# Working notes

These are the working notes behind the project: specifications written
before a feature was built, design reviews, research, and memory and size
measurements taken at each milestone. Each one is dated and kept after it
has served its purpose, because the trend across them matters as much as
any single finding: a figure that grows by 2 KB a milestone is invisible in
one report and obvious across four.

They are not documentation. Each describes the board as it was on the day
it was written, and many are now out of date: decisions changed, numbers
moved, and some of what they propose was built differently or not at all.
For how the board works today, read [README.md](../README.md) and the
reference files it points to. Where a note and those disagree, the
reference files and the source win.

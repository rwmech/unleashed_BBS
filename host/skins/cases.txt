# ===========================================================================
#  µnleashed BBS: skin.txt test cases (1.1.2)
#
#  Read by host/test_skin.cpp (the board's reader, skin_manifest.h) and by
#  tools/mkskin.py --selftest (the PC's), so the two agree on every one.
#
#  A case starts with "=== name", then "expect ok" or
#  "expect error LINE TEXT": LINE is the line of the case's skin.txt the
#  error names (0: the file as a whole) and TEXT a piece of the message.
#  The rest, up to the next "===", is the skin.txt, each line ending in a
#  newline, with \r, \t and \xHH made the bytes they name. Lines of this
#  file before the first "===" are its own comments.
#  SPDX-License-Identifier: GPL-3.0-or-later. Copyright 2026 - Robert Mech.
# ===========================================================================
